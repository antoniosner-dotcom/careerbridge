# CareerBridge

A mobile app that helps AUEB students choose their elective courses based on the career they want.

**Recommender system:** suggests courses that build the skills a chosen career needs.
**Predictive model:** forecasts how busy the student's next semester will be.

## HW1: Interactive mockup

The clickable mockup is in [`Interactive Mockup/`](Interactive%20Mockup/). Download the repo and open `index.html` in a browser. No installation is needed.
